> This is only possible by utilizing the [svgr](https://react-svgr.com/docs/cli/) npm module to render the component

{/* */}

> This only works if you are either using VS Code, or have VSC Insiders aliased to `code`

### Generate from an URL {#generate-from-an-url}

1. {#first-you-need-to-find-an-svg-on-the-internet} First you need to find an SVG on the internet

   (I suggest [SVGRepo](https://www.svgrepo.com/) for finding open-source SVGs)
1. {#then-right-click-and-copy-image-address} Then right-click and “Copy Image Address”
1. {#then-you-just-need-to-paste-the-url-into-this} Then you just need to paste the url into this command
   
   
   
   ```
   curl "https://www.svgrepo.com/show/414849/education-library-metting.svg" \
   | npx @svgr/cli \
   | code -&
   ```
1. {#this-should-open-up-into-a-temporary-file-inside-of} This should open up into a temporary file inside of VS Code

   Once the generation is completed, it will create the SVG component right there in the editor
1. {#done} Done! 🎉

### Generate from a file {#generate-from-a-file}

1. Since we already have the file we don’t need to `curl` to grab it, and instead we can use `cat` to output the files contents directly to stdout

```
cat temp.svg | npx @svgr/cli | code -&
```

1. {#this-should-open-up-into-a-temporary-file-inside-of-5} This should open up into a temporary file inside of VS Code

   Once the generation is completed, it will create the SVG component right there in the editor
1. {#done-3} Done! 🎉
