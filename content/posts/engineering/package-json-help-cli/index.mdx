#### 1\. Installation (optional) {#installation-optional}

Install the “fx” package from npm globally. It’s a JSON Explorer UI in the terminal {#install-the-fx-package-from-npm-globally-it-s-a}

```
npm i -g fx
```

> if you wish to skip this step, replace all the instances of `fx` with `npx fx`

#### 2\. Create Alias {#create-alias}

Create this alias in your terminal rc. For bash it will be `~/.bashrc` and Zsh it will be `~/.zshrc` {#create-this-alias-in-your-terminal-rc-for-bash-it}

```
alias npm-help="cat package.json | fx '.scripts'"
```

#### 3\. Restart the terminal session {#restart-the-terminal-session}

Either close the terminal and repoen it, or run `source` on teh file you just added the alias to {#either-close-the-terminal-and-repoen-it-or-run-source}

ex `source ~/.zshrc` {#ex-source-zshrc}

#### 4\. Use the new npm help command! {#use-the-new-npm-help-command}

```
> npm-help

{
  "dev": "next",
  "dev:storybook": "npm run storybook",
  "build": "next build",
  "start": "next start",
  "storybook": "start-storybook -p 6006",
  "build-storybook": "build-storybook"
}
```

#### (extra) Use grep for larger projects {#extra-use-grep-for-larger-projects}

```
> npm-help | grep 'storybook'

  "dev:storybook": "npm run storybook",
  "storybook": "start-storybook -p 6006",
  "build-storybook": "build-storybook"
```
