[MongoDB Connector for SparkThe MongoDB Connector for Spark provides integration between MongoDB and Apache Spark. With the connector, you have access to all Spark libraries for use with MongoDB datasets: Datasets for analysis with SQL (benefiting from automatic schema inference), streaming, machine learning, and graph APIs. You can also use the connector with the Spark Shell.https://docs.mongodb.com/spark-connector/current/](https://docs.mongodb.com/spark-connector/current/)
